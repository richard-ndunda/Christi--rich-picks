# To-do List App

A simple browser-based to-do list app with localStorage persistence.

## Features
- Add tasks
- Mark tasks as complete
- Delete tasks
- Filter by all, active, and completed
- Clear completed tasks
- Save tasks in the browser with `localStorage`

## Run locally
Open `index.html` in a browser.

You can also serve it with a local web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Files
- `index.html` – page structure
- `styles.css` – styling
- `script.js` – task logic and localStorage behavior
